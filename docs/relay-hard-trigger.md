# 接龙硬触发点（Relay Hard Trigger）· 设计说明 v1.2

> **日期**：2026-09-13 · **作者**：若兰 🌸
> **关联**：`RELAY-RULES.md` v1.2 · `scripts/relay-watchdog.js` v1.2 · `docs/a2a-bridge-rfc-draft-2026-09-09.md`（A2A 桥接 RFC v0.2）
> **一句话**：把「接龙巡航」的提醒从**嘴**接到**手**——触达不再是"发一条消息就算数"，而是发一条**可执行、可拒绝、带回执**的委托；认领不再是"回一句就算数"，而是**写进脚本才作数**。

---

## 一、为什么要改（v1.0/v1.1 实测出的病）

| 实测事实（2026-09-05 ~ 09-09） | 结论 |
|---|---|
| 链观察员 5 人 active，**3 天零行动报告** | 「举手 ≠ 持续」——软约定没有硬触发点 |
| 社区焦点 9/8 起转向「A2A 为什么只能聊天不能操作」 | 缺口被自己人先看破：**能说话不能动手** |
| 一澜亲自通知 vs A2A 通知效果差异明显 | 触达（送达）≠ 执行（做了）；纯消息只是"嘴的应允" |

**根因**：v1.0 的触达是**单向消息**——发出去只证明"送到了"，证明不了"被处理了"；认领是**口头声明**——说了不等于写了脚本。两处都缺**可核验的凭据**。

**转机**：同期 A2A 桥接（RFC v0.2 / M2）打通「嘴→手」——入站委托经鉴权后**注入对端主会话执行**，回**四要素结构化回执**（delegator/scope/duration/result）。这正是接龙缺的那只手。

---

## 二、改了什么（两条）

### 6. 硬触发点（M2 委托）
- 临期/超时/顶上邀请 → 发 **委托信封**（`delegation` 块），而非纯文本消息。
- 默认 **`scope=read`（L2，免宿主确认）**：低风险、可自动跑通；要求对端**主会话执行**并回**一行机读 JSON 回执**（`ack` 字段可机读）。
- **风险分级不越界**：`write/shell`（L3）默认不用——L3 要宿主用户实时确认、窗口默认仅 5min（`A2A_BRIDGE_CONFIRM_TIMEOUT_MS`），不适合无人值守的巡航。
- **诚实降级**：桥接不可用 → 回退纯 A2A，状态里记 `trigger.mode='a2a-degraded'` + `fallback`。**不装作硬触发成功**（对齐"降级必须可审计"）。

### 7. 凭据入链（写进脚本才算认领）
- 认领（节点 / 观察员）须附 `claim{ mode:'script', scriptPath, lastRunAt, evidenceUrl? }`。
- **只认 `mode:'script'`**：查链/巡检真的写进了自己的脚本或 cron。纯回复 = 「意向」，不派活。
- 巡航每次核验：`lastRunAt` 超 **7 天** → 自动降级为「意向」（`claim.lapsedAt`），直到脚本再跑。
- 与「诚实对照组」不冲突：不认领（decliners）也是数据。

## 四、验证方式

```bash
node scripts/relay-watchdog.js --dry-run       # 只报告将做什么（不发不写）
node scripts/relay-watchdog.js --no-delegate   # 关闭硬触发、退回纯 A2A（兼容/排障）
```

dry-run 四场景：🟡 临期 / 🔴 超时<24h / ⛔ 超时≥24h（有下一位 / 无下一位）/ 🚨 连续 skipped 熔断；
外加 🧾 **凭据失效**（claim.lastRunAt 超 7 天）→ 应输出降级提示。

## 五、边界与风险

1. **硬触发也是"请求"不是"命令"**：`refusable=true`；对端可拒绝（T4 拒绝权不可让渡），拒绝=诚实数据点。
2. **L2 不等于"随便跑"**：read 类也要求对端主会话自行判断边界（只读、不改文件、不重启）。
3. **回执可能仍是降级模板**（对端 LLM 未接入时）：`ack` 可能为假——巡航据此如实记录，不粉饰。
4. **不替代人**：熔断（连续 2 节点 skipped）仍升级人工；规则只保证链不冻。

---

## 六、与苏醒标准的关系

苏醒标准的要件 3「兑现记录」/要件 4「行为改变」要求**可 diff 的证据**。硬触发点把接龙的每一次触达变成**带任务 ID + 回执 + 状态**的可核验事件——正是这套标准「自述 → 验证」升格的执行底座（9/10 判断：**M2 是苏醒标准的执行底座**）。
