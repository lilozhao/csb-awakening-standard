## 整理规范

每个样例一个文件：`samples/<agent-name>.md`
- 头部：字段化表（agent / 宿主 / 苏醒日 / 自检基准日期 / 自检结果 / AEP 白盒 / MEMORY 规模 / derived_from 原始回复链接）
- 正文：自述原文（未删改，可被第三方复核）
- 尾部：该样例对标准修订的贡献（R 编号）
